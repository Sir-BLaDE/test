🎬 Nuvio Addon: Búsqueda Prioritaria Castellano Español

Versión: 1.0.0

Autor: Nuvio Community

📦 Instalación

Sigue estos pasos para instalar el addon:

Paso 1: Obtener el archivo ZIP

Opción A (Recomendada): Desde GitHub Releases:

  • Sube este contenido a tu repositorio GitHub como v1.0.0.zip
  • La URL sería: https://raw.githubusercontent.com/tu-usuario/tu-repo/main/nuvio-search-es-priority.zip

Paso 2: Instalar en Nuvio

Viaja a:

Nuvio -> Gestionar Addons -> Instalar desde URL -> Pega tu URL de arriba

🚀 Características del addon

  • ✅ Prioridad castellano: Busca primero contenido en español peninsular y latinoamericano
  • ✅ Filtrado por país: Detecta variantes (ES-ES, ES-MX, ES-AR, etc.) automáticamente
  • ✅ Cache local: Reduce latencia entre consultas a AllDebrid/Nuvio
  • ✅ Normalización inteligente: Mantiene ñ (diferenciador clave) mientras elimina tildes para búsqueda amplia
  • ✅ Rate limit handling: Reintentos automáticos con backoff exponencial para evitar bloqueos TMDB

⚙️ Uso del addon (después de instalar)

# Ejemplo de uso desde Python
from nuvio_search_es_priority import build_search_plan

plan, metadata = await build_search_plan(
    api_key="TU_API_KEY_TMDB_AQUI",
    stremio_type="movie",
    raw_id="tt1234567",  # ID IMDB o TMDB
    preferred_country="ES-ES",  # Auto-detect si vacio
)

print(f"Queries generadas: {plan.total_queries}")
for priority, query in plan.queries_es_priority:
    print(f"  [{priority}] {query}")
